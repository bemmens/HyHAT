This repository contains BOMs, CAD files and python scripts (Jupyter Notebooks), to be used as an example for the construction of the Hybrid Holographic Acoustic Tweezers described in the following paper:
https://www.overleaf.com/project/6aecb9fd43288c92d020df06 (update with DOI when available)

- The Devices folder contains CAD files and BOMs to be used as an example to construct:
    - The HyHAT device
    - A connector for the Hypertronics 160 socket compatible with the Verasonics Vantage system. 

- The Modelling folder contains Jupyter notebooks that demonstrate how to generate a .stl file that can be used to 3D print a lens for the HyHAT.

- Code to use a Verasonics Vantage System to control the array can be found at: https://github.com/bemmens/Verasonics-Acoustic-Tweezer
